Resume Analyzer:
Resume Analyzer is a Flask-based web application that analyzes resumes, evaluates ATS compatibility, matches resumes with job descriptions, and recommends suitable job roles based on detected skills and NLP similarity.

Features:
1.Resume PDF Upload and Text Extraction
2.Skill Detection and Missing Skill Analysis
3.Resume Score and ATS Score Calculation
4.Job Description Matching
5.TF-IDF and Cosine Similarity Based NLP Matching
6.Job Role Recommendation
7.Course Recommendation System
8.User Registration and Login
9.Secure Password Hashing and Session Management
10.Resume Analysis History
11.MySQL Database Integration

Tech Stack:
1.Python
2.Flask
3.MySQL
4.HTML
5.CSS
6.Scikit-Learn
7.pdfplumber

Key Learning Outcomes:
1.Flask Web Development
2.Database Integration with MySQL
3.Authentication and Session Management
NLP using TF-IDF and Cosine Similarity
Modular Application Architecture
Resume Analysis and ATS Evaluation
