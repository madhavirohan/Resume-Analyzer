# Resume Analyzer 

 Resume Analyzer  is a Flask-based web application that analyzes resumes, evaluates ATS compatibility, matches resumes with job descriptions, and recommends suitable job roles based on detected skills and NLP similarity.

## Features

* Resume PDF Upload and Text Extraction
* Skill Detection and Missing Skill Analysis
* Resume Score and ATS Score Calculation
* Job Description Matching
* TF-IDF and Cosine Similarity Based NLP Matching
* Job Role Recommendation
* Course Recommendation System
* User Registration and Login
* Secure Password Hashing and Session Management
* Resume Analysis History
* MySQL Database Integration

## Tech Stack

* Python
* Flask
* MySQL
* HTML
* CSS
* Scikit-Learn
* pdfplumber

## Key Learning Outcomes

* Flask Web Development
* Database Integration with MySQL
* Authentication and Session Management
* NLP using TF-IDF and Cosine Similarity
* Modular Application Architecture
* Resume Analysis and ATS Evaluation
